# Python.org Recreation

A modern, accessible, and responsive recreation of the official [Python.org](https://www.python.org/) website built with **React** and **Vite**.

## ✨ Features

- **Fully Responsive Design**: Fluid layouts optimized for mobile devices (320px+), tablets, laptops, and ultra-wide desktop monitors.
- **Interactive Navigation**: Header featuring the Python logo, desktop links, and an animated mobile drawer menu.
- **Hero Section**: Showcasing Python's core strengths, quick action downloads, documentation links, and an interactive code terminal with syntax highlighting and 1-click clipboard copying.
- **Ecosystem & Resources Grid**: Responsive card grid highlighting Python getting started guides, documentation, downloads, and developer jobs.
- **Complete Footer**: Multi-column responsive footer organizing About, Community, Documentation, and PSF resources.
- **Accessible & Clean**: Fast load times, semantic HTML5 tags, keyboard navigation, and zero layout shift.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/anashenastray/Python.grg.git
cd Python.grg

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
